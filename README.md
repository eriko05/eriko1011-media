# 体験セッション募集ページ（ペライチからの移行版）

## ファイル構成
- index.html … 体験セッションのページ（トップページ）
- media/index.html … 学びの動画ライブラリ（`/media/` で開くページ）
- images/ … 画像（Web用に軽くしたもの）

## 動画の追加・変更
`media/index.html` の中ほどにある `const ITEMS = [` のリストを書き換えます。
- `url`：YouTube のURL（「限定公開」か「公開」にする）、Googleドライブの共有URL など
- `title`・`category`・`desc`：タイトル、カテゴリ、説明文
- `kicker`・`catch`：サムネイルの左上の札と大きい文字（`**ここ**` が強調、`\n` が改行）

## 公開
- Vercel で公開しています。`main` ブランチに変更が入ると自動で更新されます。
- `vercel.json` はアドレスの最後に `/` を付ける設定です。

## よく変える所
- 申込みリンク（STORES）：`dxxxpbbbisuse.stores.jp` で検索すると出てきます（2か所）
- ページ内の申込みボタン：`href="#apply"` は、ページ下の申込み欄に移動します
- 料金や受付日時：「体験セッション（1時間）」の周辺
- 色：`<style>` の先頭にある `--pink` などの値

## 注意
- ペライチで使っていたチューリップの画像（PIXTA素材）は、ペライチの中でしか使えないため入れていません。代わりにバラの画像を使っています。
- そのほかの写真も、フリー素材などの場合は、ペライチ以外のサイトで使ってよいか利用規約を確認してください。
- 公開したら、SNSでシェアしたときの画像（og:image）が正しく出るように、`images/hero.jpg` の指定を絶対URL（https://〜/images/hero.jpg）に変えてください。
